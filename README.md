# حكايتي – Hikayaty

## النشر على GitHub Pages
1. افتح مستودع GitHub الخاص بالموقع.
2. ارفع الملفات الثلاثة كما هي في المجلد الرئيسي: `index.html`, `style.css`, `script.js`.
3. من Settings > Pages اختر Deploy from a branch ثم `main` و`/(root)` ثم Save.
4. افتح رابط GitHub Pages بعد اكتمال النشر.

## ما الذي يعمل في هذه النسخة؟
- واجهة عربية RTL متجاوبة.
- إدخال اسم الطفل والعمر واختيار عالم القصة ونوع الكتاب.
- معاينة صورة الطفل داخل صفحات الكتاب.
- نص قصة أولي من قوالب جاهزة بحسب المغامرة.
- تحويل مبسط للصورة إلى تدرجات أبيض وأسود لصفحة تلوين.
- الطباعة أو الحفظ PDF عبر نافذة الطباعة في المتصفح.

## حدود مهمة بشفافية
هذه نسخة ثابتة تعمل على GitHub Pages دون خادم أو تثبيت برامج. لا تستخدم حتى الآن نموذج ذكاء اصطناعي لتأليف قصة فريدة أو رسم مشاهد جديدة؛ النصوص مبنية على قوالب، وتحويل الصورة إلى تلوين معالجة بسيطة وليست رسماً خطياً احترافياً. الصورة لا تغادر متصفح العميل في هذه النسخة. لا يوجد تخزين للطلبات أو لوحة إدارة.

لإضافة توليد حقيقي بالذكاء الاصطناعي مع استقبال الطلبات، نحتاج لاحقاً إلى خدمة خلفية آمنة تحفظ مفاتيح API وتدير الملفات والطلبات. لا تضع مفتاح API سرياً داخل ملفات GitHub Pages العامة.
