# حكايتي | Hikayaty

نسخة أولية لواجهة مشروع حكايتي، موقع عربي RTL لتجربة إعداد قصة شخصية وكراسة تلوين للأطفال.

## تشغيل محلياً
1. افتح المجلد في VS Code.
2. افتح `index.html` في المتصفح، أو استخدم إضافة Live Server.
3. جرّب إدخال اسم الطفل ورفع صورة واختيار نمط القصة.
4. ستظهر معاينة أولية لمخطط الكراسة.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub باسم `hikayaty`.
2. ارفع الملفات الثلاثة: `index.html`, `style.css`, `script.js` وملف README.
3. من المستودع افتح Settings ثم Pages.
4. في Build and deployment اختر Deploy from a branch.
5. اختر Branch: `main` والمجلد `/ (root)` ثم Save.
6. انتظر حتى يظهر رابط الموقع في صفحة Pages.

## ملاحظات مهمة
- هذه واجهة Frontend تجريبية فقط.
- اختيار الصورة ومعاينتها يتم محلياً في المتصفح ولا يتم إرسالها إلى خادم.
- لا يوجد حتى الآن توليد فعلي للنصوص أو الصور بالذكاء الاصطناعي.
- زر الطباعة يطبع صفحة المعاينة التنظيمية، وليس كراسة PDF النهائية.
- لا تضع مفاتيح API أو كلمات مرور داخل ملفات JavaScript المنشورة على GitHub Pages.
- ربط الذكاء الاصطناعي وتوليد صفحات القصة وملف PDF يتطلب Backend آمن، وسيكون ذلك في مرحلة لاحقة.
